# Mini Programmer Pack — Version 2

Mobile-first GitHub Pages landing page for a ₹49 digital programming pack.

## Files
- `index.html` — page, product preview, ad slot and checkout section
- `style.css` — responsive design
- `script.js` — prevents the purchase button from pretending checkout is live

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## Connect payment
In `index.html`, find `data-payment-url=""` and replace the empty value with your real checkout/product URL after you have a legitimate payment/delivery setup.

## Ads
The page includes an ad placeholder. Replace it only with the official code supplied by an approved ad provider after your site/account is eligible.
